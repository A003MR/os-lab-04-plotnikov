## Что пошло не так (Troubleshooting)
В ходе работы проблем с доступом не возникло. Однако при попытке прочитать логи ядра через `dmesg` (Задание 4) система выдала ошибку доступа. Это связано с политикой безопасности Fedora (`kernel.dmesg_restrict=1`), которая запрещает обычным пользователям читать логи ядра. Для просмотра требуется выполнение команды с `sudo`. Также при запуске скрипта `eat.py` с лимитом `ulimit -v 307200` процесс упал не на 300 МБ, а раньше (на 60 МБ), так как интерпретатор Python сам по себе занимает значительную часть виртуальной памяти при запуске.
